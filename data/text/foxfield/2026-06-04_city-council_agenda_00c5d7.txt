Call to Order  
The meeting was called to order at 6:30 p.m. via Microsoft Teams. 
1. Oath of Office for Appointed Board Member, Doug Hodge
2. Pledge of Allegiance
3. Roll Call
The following Trustees were present in person: Mayor Jones, Trustee Hodge, Trustee
Lawrence, Trustee Pakanati, Trustee Schultz, and Trustee Thompson.
A quorum was present. 
4. Audience Participation
none
5. Consent Agenda
Mayor Jones moved to approve the minutes, seconded by Trustee Schultz. Passed
unanimously.
6. Public Hearing
a. Town of Foxfield Land Use Code
Mayor Jones opened the Public Hearing. There were no public comments.  Mayor 
Jones closed the public hearing. The Board discussed the review produced by Copilot 
and the points that were brought up. A decision was made to submit the copilot 
review to Austin for review. 
b. Ordinance 2026-02 Amending Articles 1-6 of Chapter 16 of the Foxfield Municipal
Code to Update the Land Use Code-FINAL READING
Mayor Jones moved to postpone Ordinance 2026-02 Amending Articles 1-6 of 
Chapter 16 of the Foxfield Municipal Code to Update the Land Use Code on final 
reading to a later date, seconded by Trustee Lawrence. Passes unanimously. 
Item #4a
7. For Discussion
a. Hinsdale Traffic Calming 2026 Update
Trustees discussed the traffic data and mentioned how it does not reflect that
there is a speeding issue. The data is similar to the data that was previously
collected. Trustees questioned how the data is collected and if the number is
pulled from initial speeding or from when the vehicle slows down. Trustee
Pakanati is going to craft questions to ask. Trustee Thompson talked about
previous data that was collected for the gates and the need to be consistent in
this data collection. When data was collected for the gates, several data points
supported the need for the gates. Trustees agreed to do some more work on this
and then decide.
b. Ordinance 2026-03 Amending Chapter 18 of the Town of Foxfield Municipal
Code by the Addition Thereto of a New Article 13 Adopting the Wildfire
Resiliency Code by Reference
Mayor Jones stated that the Town Attorney strongly suggested we adopt this 
due to state requirements. Trustees asked for clarification on how this applies to 
the Town, when this needs to be adopted, and repercussions of not adopting. 
Trustees agreed to read the Wildfire Resiliency Code and present questions at 
the next meeting.  
c. Town Projects Trustee Leads
Ms. Proctor explained the Town project list. Trustees agreed with their projects.
8. F
or Possible Action
a. 2025 Audited Financial Statements
Ms. Proctor explained the audited financial statements.
Mayor Jones moved to approve the 2025 Audited Financial Statements as
presented, seconded by Trustee Hodge. Passes unanimously.

eports

talked about some problem properties and how Cameron addressed

. Lisa Jones said there are several people interested in the home rule

been ordered, but it could take a couple of months to receive

repairs crossed the sprinkler line and to find the wire for the
